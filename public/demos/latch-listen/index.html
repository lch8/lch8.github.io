What runs on the device

Every 5 ms, the selected front end checks a 16 kHz mono stream. The waveform matcher searches sample delays using an inverse noise spectrum. The STFT matcher compares how energy rises and decays across 16 bands. Either can send a 50 ms candidate to the same 401-parameter station verifier. Microphone capture runs one selected detector.
