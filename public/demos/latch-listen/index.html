Implementation

What runs on the device

A causal high-frequency energy gate tracks the local noise floor every 5 ms. A candidate opens a 50 ms buffer. The verifier scores its frequency distribution and decay, then emits a timestamp.

The station profile uses a 401-parameter PyTorch head trained on CPU from two buckle takes and tool negatives. The unseen-buckle profile uses a linear head. Both run as plain JavaScript in the browser.

These are seat-belt buckle recordings. Confirmation of a particular assembly would require recordings and independent mechanical labels from that station.
